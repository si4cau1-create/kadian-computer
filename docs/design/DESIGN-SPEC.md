> 设计稿版本：v1（2026-10-31）
> 设计源文件（可编辑画布，有浏览器权限时可直接查看）：https://ardot.tencent.com/file/742166698106455
> 本目录 `img/` 内为 6 张高保真界面图，供视觉参考。
> 适用范围：`kadian`（PWA / 电脑端）与 `kadian-android`（WebView 壳，视觉随 PWA，无需改动）。

## 0. 给开发智能体的任务说明（可直接复制）

请按本规格改造 `kadian` 项目的界面层，目标是「视觉升级 + 桌面端工作台化」，**不改动任何业务逻辑与数据模型**（IndexedDB schema、SM-2、掌握度模型、AI 调用链一律不动）。

优先级：

1. **P0 设计系统对齐** —— 用第 1 节的 token 替换 `assets/css/app.css` 的 `:root`，统一描边与圆角（第 2 节）。
2. **P0 底部导航胶囊化** —— 替换现有 `.tabbar/.tab`（第 3.6 节）。
3. **P1 手机端 6 屏视觉还原** —— 按第 4 节逐屏调整间距、层级、配色（第 4 节）。
4. **P1 桌面端两栏工作台** —— ≥1024px 时做题页改为「语篇主区 + 右侧精讲检查器」两栏（第 5 节）。
5. **P2 状态补齐** —— loading / empty / error 三态视觉统一（第 6 节）。

验收：手机 390×844 与桌面 1440×960 两档下与 `img/` 中图片视觉一致（允许 ±4px 间距误差）；所有交互路径与现有行为完全一致。

## 1. 设计系统 Token

**沿用项目既有配色基因，只做两处升级**（描边加粗、圆角微调），不另起炉灶。

```css
:root {
  /* ---- 表面 ---- */
  --bg:            #F6F6F3;   /* 页面底：暖白纸感 */
  --card:          #FFFFFF;   /* 卡片 */
  --surface-sunk:  #F4F4F1;   /* 凹陷块：分段控件底、灰按钮 */
  --surface-tint:  #FAFAF7;   /* 浅底块：语境框、题目卡底 */

  /* ---- 描边（本次升级：0.5px → 1px，高 DPI 下不再发虚） ---- */
  --line:          #E8E8E2;   /* 常规描边 */
  --line-2:        #E2E2DC;   /* 强描边：输入框、可点按钮 */

  /* ---- 文字 ---- */
  --text:          #1C1C1A;
  --text-2:        #3C3C38;   /* 正文强调 */
  --muted:         #6B6B66;
  --faint:         #9A9A94;

  /* ---- 主色（品牌蓝） ---- */
  --accent:        #378ADD;
  --accent-ink:    #185FA5;   /* 深：主色文字、主色块上的深字 */
  --accent-soft:   #E6F1FB;   /* 浅：标签底、选中项底、进度轨道 */

  /* ---- 语义色 ---- */
  --ok:            #3B6D11;   --ok-soft:     #EAF3DE;
  --warn:          #BA7517;   --warn-soft:   #FDF4E7;
  --danger:        #A32D2D;   --danger-soft: #FCEBEA;

  /* ---- 圆角 ---- */
  --radius-lg:     14px;      /* 大卡：语篇卡、精讲卡、主线卡 */
  --radius:        12px;      /* 常规卡：统计卡、列表卡 */
  --radius-sm:     9px;       /* 按钮、输入框、小卡 */
  --radius-pill:   999px;     /* 胶囊：chip、tab 栏容器 */

  /* ---- 阴影（克制，只给浮层用） ---- */
  --shadow:        0 1px 2px rgba(28,28,26,.04), 0 8px 24px rgba(28,28,26,.05);
}
```

字体：

```css
body { font-family: "Noto Sans SC", -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif; }
.zh   { font-family: "Noto Sans SC", sans-serif; }   /* 界面中文 */
.ja   { font-family: "Noto Sans JP", sans-serif; }   /* 日文语篇与例句 */
.latin{ font-family: Inter, system-ui, sans-serif; } /* 英文语篇、题号、数字 */
```

排版规范：

| 用途 | 字号 / 行高 | 字重 | 备注 |
|---|---|---|---|
| 页面标题（4 屏统一） | 24px / 1.3 | 700 | **所有屏标题必须一致**，不因页面变化 |
| 主线大标题 | 24px / 1.3 | 700 | 白字（蓝底上） |
| 卡片标题 | 14–15px / 1.4 | 600 | |
| 正文 | 13.5–14.5px / 1.75 | 400 | 语篇类内容 1.85–2.05 |
| 辅助文字 | 12–12.5px / 1.5 | 400 | `--muted` / `--faint` |
| 标签 chip | 11–12px | 400–500 | |
| 数值（统计） | 24–28px / 1.25 | 600 | 数字用 Inter |

## 2. 组件规格

### 2.1 卡片
- 白底 `--card`，1px `--line` 描边，圆角 12（大卡 14），内边距 14（小）/ 16（中）/ 20–24（大）。
- **不加大阴影**；仅弹窗（`.modal`）保留 `--shadow`。
- 卡片之间纵向间距 16（列表内 10–12），横向 12–16。

### 2.2 按钮
| 类型 | 背景 | 文字 | 描边 | 圆角 | 内边距 |
|---|---|---|---|---|---|
| 主按钮 | `--accent` | 白 600 | 无 | 10 | 10×16 |
| 次按钮（幽灵） | 白 | `--text` 500 | 1px `--line-2` | 9–10 | 8×13 |
| 灰底按钮 | `--surface-sunk` | `--accent-ink` | 无 | 8 | 5×10 |
| 蓝底白字反向（蓝卡内） | 白 | `--accent-ink` 600 | 无 | 10 | 9×16 |

点击态：`transform: scale(.98)`；禁用态：文字 `--faint` + `disabled`。

### 2.3 标签 chip
- 圆角胶囊，内边距 2×8，12px 字。
- 分类标签（浅蓝底 `--accent-soft` + `--accent-ink` 文字）/ 状态标签（灰底 `--surface-sunk` + `--muted`）/ 语义标签（`--ok-soft`/`--warn-soft`/`--danger-soft` 配对应深色）。
- 学科标签固定用浅蓝底：日语/英语 `--accent-ink`；未适配学科用 `--faint` + 虚线感（灰底灰字）。

### 2.4 进度条（掌握度）
- 轨道高 6px、圆角 3、`#EFEFF0`；填充同高圆角 3。
- 颜色：<40% `--warn`；40–70% `--warn`→`--accent` 过渡；≥70% `--ok`（本设计稿统一用 `--warn` 表达"薄弱"）。

### 2.5 分段控件 / 芯片行
- 分段控件：容器 `--surface-sunk` 底、圆角 9、内边距 3；选中项白底圆角 7、内边距 6×16、13px 500 字。
- 筛选 chip 行：胶囊、5×12；选中为 `--accent` 实心白字，未选中白底 1px `--line-2`。

### 2.6 底部导航（本次重点改造：扁平 → 胶囊）

现状 `.tabbar` 是贴底整宽扁平条；**改成胶囊**：

```
.tabbar        容器：贴底固定，背景透明，padding 12px 21px 21px（21 = 安全区底部）
  .tabbar-pill 胶囊：白底，1px --line 描边，圆角 36，高 62，width 100%，内边距 4
    .tab        每项：flex 1，高 62，圆角 26，竖排 gap 3，图标 18px + 文字 11px
      激活态     背景 --accent 实心，图标与文字均为白
      非激活态   透明背景，图标与文字均为 --faint
```

- 胶囊外层需 `--shadow` 或 1px 描边以在浅底上浮起；建议胶囊再加 `backdrop-filter: blur(12px)`（可选）。
- 图标沿用 `main.js` 中 `TABS[].icon` 的 SVG path（家/铅笔/文档/对勾圆/调节杆），仅线宽 1.7、尺寸 18。
- **安全区**：底部 padding 用 `max(21px, env(safe-area-inset-bottom))`。
- **内容区不得被遮挡**：`.view` 底部 padding 需 ≥ 胶囊高 62 + 上下 padding 33 ≈ **95px**（现状 84px 偏小，需上调）。

### 2.7 就地精讲卡（产品核心组件，务必一致）
- 白底、**1.5px `--accent` 描边**（`#BBD5EF`）、圆角 14、内边距 14–16。
- 内部从上到下：
  1. 顶行：知识点名（15–19px 600）+ 状态 chip（`已缓存 · 不再花额度`，灰底 11px）
  2. 来源行（12px `--faint`）：`来自本段语篇` / `选自语篇第 1 行 · xxx`
  3. 1px 分隔线 `#EFEFF0`
  4. 释义（14px / 1.75）
  5. 例句块：`--surface-tint` 底、圆角 9、内边距 12；原文（13.5px）+ 中文（12.5px `--muted`）
  6. 「用法」行：浅蓝底小标签 + 说明（13px）
  7. 「常见误用」行：浅橙底小标签 + 说明（13px）
  8. 操作行：主按钮「学会了，入库」+ 幽灵按钮「没懂，再讲简单点」
  9. 底注（11.5px `--faint`）：`入库后按遗忘曲线安排复习 · 同一片段只讲一次，不再消耗额度`

### 2.8 即点高亮（语篇内可点词）
- 浅蓝底 `--accent-soft` + 1px `--accent` 描边 + 圆角 4 + 左右 2–3px 内边距，文字 `--accent-ink` 500。
- 桌面端可用虚线下划线（`border-bottom: 1.5px dashed var(--accent)`）代替底色，二选一，全局统一。

### 2.9 搜索框
- 白底、1px `--line` 描边、圆角 10、内边距 11×12、图标 16px `--faint`、占位文字 13px `--faint`。
- 桌面端顶栏内为胶囊形（圆角 999、`--surface-sunk` 底）。

- 桌面端鼠标划词提问后，讲解**不再插在语篇下方**，而是出现在右侧面板；手机端保持插在语篇下方。
- 实现方式：`@media (min-width:1024px)` 下给 `#/quiz` 视图加 `.qz-workbench{display:grid;grid-template-columns:1fr 400px;gap:20px}`，把 `#qzExplains`（精讲卡容器）移到右栏（DOM 顺序：语篇+题目在左，`#qzExplains` 在右）。手机端维持现有单列 DOM 顺序，用 CSS `order` 或直接在不同断点下切换容器即可——**推荐直接切换 DOM 归属**（避免 `order` 造成的 tab 顺序错乱）。
