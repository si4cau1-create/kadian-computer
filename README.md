# 卡点 · 做题流学习工具

**遇到不会的，当场就讲给你听——不跳页、不掏手机、不开浏览器，拖延症没有可乘之机。**

卡点是一个本地优先（local-first）的 PWA 学习工具，为「语境滚动 + 即时精讲」学法设计。
它不卖"题库有多大"，核心竞争力只有一条——**全程无断点的闭环**：

> ### 做题 → 不会 → 了解 → 学会
>
> 在做题中触到陌生单词、语法点 → **就在答题界面里就地展开精讲**（释义、例句、用法，看懂即走）→ 点一下「学会」入库，之后按遗忘曲线自动找上你复习。
>
> **「不会」到「了解」是整条链里最重要的一段：直达讲解，零跳转、零等待、零借口。**
> 从"遇到不会"到"弄懂"中间不给你留任何"待会儿再查"的空档——拖延症没有可乘之机，这就是本产品存在的理由。

**适用科目：日语、英语。** 这两科最吃固定语法和词汇的积累，"在真实语篇里做题、当场解决陌生点"的学法，在这两科上收益最大。

数据只存在你自己的设备上，不注册、不上传（唯一联网行为是调用你配置的大模型接口）。

**许可证**：GPL-3.0（见 [LICENSE](LICENSE)）。

## ⚠️ 版本说明（下载前必读）

**1.x 系列（含 1.1.0）体现的是早期错误的产品理念，请勿作为学习主力下载使用。**

早期版本把「拍照搜题 / 整题解析」当成了产品核心，还为它内置了一个约 23MB 的本地 OCR 引擎。
这条路已被实测证伪：

- 轻量 OCR 错题百出，识别质量比不过任何云端视觉模型，"离线识别"是个伪需求；
- 要拍照求解解析，直接用豆包等免费工具更好——没有理由用一个 App 的半吊子识别。

**正确理念是 2.0.Beta 的「全程无断点做题流」**（即本页开头所述），即将发布。
本仓库存档 1.1.0 仅为留档与参考；想认真用这个工具学习的，请等 2.0.Beta，**不要下载 1.x 版本**。

## 快速开始

```bash
# 电脑上启动（Python 3.8+，零依赖）
python tools/serve.py          # 默认端口 8765
python tools/serve.py 9000     # 指定端口
```

启动后：

- **本机打开**：http://127.0.0.1:8765/
- **手机打开**：http://`电脑局域网IP`:8765/（与电脑连同一个 WiFi）

手机浏览器打开后 → 分享 / 「添加到主屏幕」，即可以 App 形态全屏使用，离线也能打开。
Windows 也可以直接双击 `start.bat`。

## 2.0.Beta 规划（正确方向）

| 环节 | 形态 |
| --- | --- |
| 做题 | 内置预设题库**先留空**；出题走**已配置的大模型 API 生成**（日语 / 英语真实语篇与真题优先） |
| 不会 | 做题界面内直接触点陌生单词 / 语法点 |
| 了解 | **就地展开精讲卡**：系统预置提示词保证讲解直达，不跳页、不需要用户自己组织提问 |
| 学会 | 一键入库 → SM-2 间隔复习（复用现有卡点库与掌握度模型） |

同时：移除本地 OCR（拍题方向已否，约 23MB 死重量）；视觉模型角色从「拍题解析」改为「即时精讲后端」；修复答题区与系统状态栏重叠等 UI 问题。

## 本存档版（1.1.0）说明

以下内容描述的是**已废弃的 1.1.0 存档版**功能，仅作参考：

- 「拍照问」：拍照 → 本地 OCR（tesseract 三语，约 23MB）转文本后划选精讲，或云端视觉模型整题讲解
- 卡点库、SM-2 间隔复习、AI 按薄弱点出题、掌握度模型、语篇划选、JSON 备份导出导入
- 首次使用需在「设置」填 AI 服务（base_url + API Key + 模型名），配置只保存在本机浏览器

## 技术说明

- 纯静态前端，零构建、零 npm 依赖；原生 JS + IndexedDB（localStorage 自动降级）。
- KaTeX 本地化渲染 LaTeX 公式。
- OCR 双引擎（1.x 遗留，2.0.Beta 移除）：本地 tesseract.js 5.1.1（wasm，离线）/ 云端视觉模型；语言包为解压后的 `.traineddata` 原始格式，浏览器与 APK 行为一致。
- SM-2 间隔重复调度；掌握度模型：复习自评（EMA 更新）+ 练习正确率（权威信号）+ 存在卡点（初始薄弱）。
- 所有 AI 调用走 OpenAI 兼容 `/chat/completions` 接口，服务商可随时更换。
